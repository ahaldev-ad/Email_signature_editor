# SignaCraft PRO — Advanced Email Signature Studio

SignaCraft PRO is a Photoshop-grade, graphical email signature creation suite built with React and Vite. It generates 100% compliant, table-based inline-CSS HTML email signatures compatible with Gmail, Apple Mail, Outlook (Windows & Mac), and mobile mail clients.

---

## 🚀 Key Features

### 1. Minimal & Modern Social Media Logo Packs
- **6 Modern Icon Style Packs**:
  - **Minimalist Wireframe**: Clean thin vector outlines with subtle borders (`outline`)
  - **iOS Soft Squircles**: Modern Apple/macOS squircle badges with soft brand tints (`squircle_soft`)
  - **Circular Dark Chips**: Solid circular pills with inverted white icons (`circle_solid`)
  - **Pure Minimalist Monochrome**: Borderless neutral icons for executive signatures (`pure_minimal`)
  - **Neo-Brutalist High-Contrast**: Crisp solid border with bold geometric corners (`neo_brutalist`)
  - **Modern Tech Gradient**: Vibrant indigo-to-cyan gradient background badges (`gradient_glow`)
  - **Classic Simple**: Default unbordered clean icons
- **14 Supported Platforms**:
  - LinkedIn, X (Twitter), GitHub, Instagram, YouTube, Facebook, WhatsApp, Threads, TikTok, Telegram, Discord, Medium, Substack, Dribbble, Spotify, Calendly, and Website.
- **Color Modes**: Official brand colors or customizable monochrome palette.

---

### 2. Curated 1-Click Element Packs
Modular components pre-configured for instant one-click placement on your canvas:
- **Contact & Info**: Minimal Split Contact Bar (Phone • Email • Website)
- **Disclaimers**: Eco Green Printing Notice (`🌱 Please consider the environment...`), Legal Confidentiality Clause
- **CTA & Booking**: Discovery Call Booking Pill (`📅 Book 15-Min Meeting`)
- **Trust & Compliance**: SOC-2 Type II & 256-Bit SSL Security Pill, Trustpilot 5-Star Rating Widget
- **Mobile & Apps**: App Store & Google Play download badges
- **Calligraphy**: Executive Cursive Handwritten Sign-off with customizable SVG ink path

---

### 3. Free Logo & Asset Services Hub
- **Instant Domain Logo Search**: Powered by Logo.dev / Clearbit API (`https://img.logo.dev/{domain}?token=pk_anonymous`). Type any company domain (e.g. `stripe.com`, `apple.com`, `openai.com`) for live preview and 1-click placement as an image layer.
- **Popular Company Logos**: Curated 1-click grid for Google, Apple, Microsoft, Stripe, Spotify, Slack, OpenAI, Notion, Figma, Airbnb, AWS, and Uber.
- **Free Vector & Asset Directories**: Direct links and badges for:
  - **Simple Icons**: 3,000+ open-source SVG brand logos
  - **SVGL**: Modern SVG tech logos and framework icons
  - **Brandfetch**: Global brand assets and color palettes
  - **VectorLogoZone**: Clean transparent vector SVGs
  - **Unsplash Headshots**: 100,000+ high-resolution executive portrait photos

---

### 4. Photoshop-Style Graphic Workspace
- **Authentic Bezier Pen Tool (`P`)**: Vector anchor points, tangent control handles, close-path detection, and live HUD.
- **Marquee Batch Selection & Alignment**: Drag to select multiple layers or Shift-click. Align Left, Center, Right, Top, Middle, Bottom, or distribute evenly.
- **Layers Panel**: Drag to reorder, visibility toggle, lock layer, and duplicate.
- **Keyboard Shortcuts**: Photoshop-standard shortcuts (`V`, `P`, `T`, `I`, `R`, `B`, `U`, `S`, `Q`, `K`, `5`, `H`, Arrow nudging, `Cmd/Ctrl+Z`, `Cmd/Ctrl+C`, `Cmd/Ctrl+V`, `Cmd/Ctrl+D`).
- **Responsive Navigation & Mobile Drawer**: Adaptive 3-zone layout with mobile sheet and slide-out inspector drawer for smaller screens.

---

### 5. Export & Setup
- **Copy to Clipboard (Rich Text)**: Direct paste into Gmail, Outlook, or Apple Mail settings without touching code.
- **Download Clean HTML**: Standalone email-safe HTML file with table nesting and inline styles.
- **Live HTML Code Inspector**: Inspect generated markup and test client rendering.
- **Batch Team CSV Generator**: Apply team member data dynamically using `{Variables}`.
